# program-audit

Neutral audit of the research program. Findings only.

This repository never modifies an audited repository. It reads them and
records findings here.

Two passes, reported separately so their independence is legible:
- Pass 1, blind: no findings seeded, no hypotheses named in advance.
- Pass 2, targeted: specific named checks, run only after Pass 1 is committed.

Audited: AiTrader, ETFExperiment, HFExperiment, InsiderExperiment,
MLCryptoEngine, NPDExperiment, NPLExperiment, ORBExperiment, PMExperiment,
VRPExperiment, retail-power-limits, solattn, solclear.

Excluded as unrelated: [personal repo, name removed].
