## What I checked and found sound

Where the thesis did not hold, with the arithmetic where I ran it.

1. **The B.2 computation is exactly reproducible.** From the stored rankings and sealed returns I reproduce every figure in `reports/stage_b2/evaluation.md`: model +0.0061 (n 404), mom_12_1 +0.0222, logistic -0.0058, sign_last -0.0255 (:59-62); contrast -0.0161, interval -0.0673 to +0.0351, bootstrap SE 0.02562, daily sd 0.36339 (:78-82); effective n 201.2 and MDC 0.0512 (:92-93); coin interval -0.0276 to +0.0397 (:133); secondary model -0.0203, contrast -0.0300 [-0.0677, +0.0077], MDC 0.0377, n 412 (:160-173). The moving-block bootstrap (evaluator.py:160-190) reproduces with the same seeds. `recompute.out`.
2. **The "does not beat coin" row is supported at the registered floor.** The Section 9.1 floor is a one-sample test against zero with the null sd and no overlap adjustment (REGISTRATION.md:208-212). The registered within-day permutation null (Section 8, REGISTRATION.md:186; evaluation.md:101-113) is exactly that test: null sd 0.00926 on the mean (0.185695 / sqrt(404) = 0.00924), so its resolution at t 2.0 is 0.0185, inside the 0.025 floor; the observed +0.0061 gives p 0.5174. The block-bootstrap coin interval is wider (half-width 0.0337) because the realized model IC sd is 0.2516, and the no-overlap one-sample test on the realized sd gives an MDE of 0.0250 (t = +0.49). All three readings agree the model did not beat a coin. I therefore do not file the "confirms the council negative. Closed." label (evaluation.md:127) as a finding: the authors disclose the power tension in the same document ("underpowered unresolved, not a tight null", evaluation.md:139-141; "closed by operator decision, not by evidence", REGISTRATION.md:710) and the coin-level claim is adequately resolved. What is underpowered is the contrast against momentum, which the authors say plainly (evaluation.md:243-248).
3. **The 1,700-day sizing is arithmetically right on its own inputs.** (0.0512 / 0.025)^2 x 404 = 1,694 days; (2 x 0.36339 / 0.033)^2 x 3.4 = 1,649. "Roughly four times the evaluable days" (REGISTRATION.md:717) is (0.0512/0.025)^2 = 4.19. "No model has one" is true for any frontier model with a post-2020 cutoff (a 2021-09 cutoff yields about 1,190 trading days to 2026-07-24); I know of no served frontier snapshot with a 2019 cutoff, so I do not file an alternative-source finding.
4. **The window-halves diagnostic is inside noise, as stated.** With sd 0.19 and VIF 3.4 the SE per half is 0.0247 and on the difference 0.0349 (evaluation.md:256-258); 0.0124 / 0.0349 = 0.36 SE. On the realized sd 0.2516 the difference SE is 0.046 and the ratio 0.27. Sound.
5. **Section 0 coverage.** 415 stored of 432 eligible = 96.06 percent (collection.json:8-14; collection.md:30-43); GO at the 90 percent bar; `model_failed` correctly in the denominator (section0.py:34-44). Sound.
6. **Spend arithmetic.** Evidence ledger and spend ledger both sum to 6.9377835 USD (920 gate rows, 2 calibration rows), matching 6.9378 (collection.md:49); remaining 3.0622. Amendment 5's undercount is disclosed and the superseded rows are kept. Sound.
7. **Best-baseline designation (ADR-010) is conservative in the stated direction.** The model would have looked better against either other baseline: contrast versus logistic +0.0118 [-0.0397, +0.0634]; versus sign_last +0.0316 [+0.0011, +0.0621] (unanchored recomputation, block bootstrap, `recompute.out`). The sign_last contrast excludes zero, but sign_last carries a negative IC (-0.0255) and the registration fixes the contrast against the best baseline (REGISTRATION.md:181-182), so I do not file the sign_last result as a better-resolved endpoint: beating a below-coin baseline is not the hypothesis. The logistic contrast, the one most directly matched to "identical features", is no better resolved than the momentum contrast (MDC 0.0516), so hunt item 6 does not hold here.
8. **Reopen conditions with triggers already met: none inside this repository.** Every dated entry is 2026-08-25; the only later artefact is the untracked closure marker of 2026-09-02, which lifts no blocker. The stale trigger is DRAFT-all-4.
9. **Anti-contamination design.** Cutoff verified from the vendor page with the verbatim string (REGISTRATION.md:58-61), one-month guard band, per-call remapped labels, ticker-label collision fix on 52 of 432 days (session_a1_b1.md:134-138), negative control +0.0001 inside 0.02 (evaluation.md:36-42). Sound.
10. **Amendment 0 ordering and the sealed-store single reader.** The evaluator refuses on an empty Section 13 (evaluator.py:73-78), mutation 6 proves the refusal (mutations.md:76-89), and the guard test restricts the sealed path to the evaluator (build.md:85-90). Sound.
11. **Not a closure defect, noted for completeness (outside my direction):** Amendment 4 projected first-attempt compliance of 88 percent from 8 held-out days and "an expected failure rate near zero" over four `minimal` attempts (REGISTRATION.md:573-586). The ledger shows 362 stored of 813 `minimal` attempts under the strict schema (45 percent of attempts), 17 days in `model_failed`, and measured spend 6.94 USD against the 2.86 USD projection (REGISTRATION.md:579; progress.md:215-216 conflates the projection with the measurement). Coverage still fired GO, so no verdict rests on it.
